# Focar Site

Repositório público do site institucional da Focar Fora da Caixa.

## Estrutura

- `apps/site/`: aplicação Next.js pública
- `packages/content/`: conteúdo estruturado do site
- `packages/design-system/`: tokens visuais
- `packages/ui/`: primitivos compartilháveis

## Scripts

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`
- `npm run typecheck`

## Ambiente

Use `apps/site/.env.example` como contrato inicial das variáveis de ambiente.

## Publicação

Este repositório é preparado para deploy na Vercel com o diretório raiz do projeto.
